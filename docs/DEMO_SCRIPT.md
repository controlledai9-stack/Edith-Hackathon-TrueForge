# Three-minute demo script

Use synthetic/public content and a dedicated demo account. Keep both E.D.I.T.H. and the TrueForge Activity panel visible.

## 0:00–0:25 — Problem and product

- Introduce E.D.I.T.H. as a multi-mode agent workspace rather than a chat-only interface.
- Show E.D.I.T.H., Work, Research, and Homework modes.
- State that TrueForge owns the live agent session, orchestration, tool loop, approvals, and continuation.

## 0:25–1:35 — TrueForge doing real work

- Give Work Mode one small multi-step task that creates an artifact from synthetic data.
- Keep the Activity panel open.
- Point out the visible `harness_session`, planning/tool events, and approval pause.
- Approve the safe prepared action and download/open the resulting artifact.
- Avoid a task that depends on an unreliable third-party login during the judged recording.

## 1:35–2:20 — Research or Homework differentiation

- Upload a short public or synthetic source.
- Show the no-instruction clarification prompt.
- Request a concise source-grounded result or a readable homework solution.
- Show persistent source context/chunk retrieval or the separate method/formula record.

## 2:20–2:45 — Architecture and safety

- Show the architecture diagram in `README.md`.
- Explain the FastAPI product boundary, TrueForge profiles/session bridge, MCP tools, approval gates, cancellation, and local-only secrets.
- Briefly mention fallback is visibly labelled and is not the judged harness path.

## 2:45–3:00 — Review and close

- Show the representative merged GitHub pull request and completed Qodo review/follow-up trail.
- Mention the full regression-test result and AI-assistance disclosure.
- End with the public repository URL.
